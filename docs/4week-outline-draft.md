## Week 3 — 数据与多媒体：让 AI 能看、能画、能拍

**目标**：让小白发现"AI 不只是聊天框"。学完能产出图、视频，并把 AI 接入文件/资料。

| Day | 标题 | 核心收获 | 关键内容 |
|---|---|---|---|
| 1 | 让 AI 读懂你的文件 | 学会"喂资料"的最简方式 | 上传 PDF / Word / Excel / 长文本；AI 总结、提问、抽取；"外挂文件夹"概念入门（RAG 直觉版） |
| 2 | 结构化输出 | 让 AI 产出能直接用的数据 | 让 AI 输出 Markdown 表格 / JSON / 清单；复制到 Excel / 飞书；批量整理信息场景 |
| 3 | 看图说话：AI 的眼睛 | 学会用多模态读图 | 上传截图 / 照片 / 手写 / 表格让 AI 解读；日常场景：解题、读菜单、读发票、看 UI 改 bug |
| 4 | AI 生图入门 | 做出第一张满意的图 | Midjourney / 即梦 / Nano Banana 选型；prompt 公式（主体 + 风格 + 构图 + 光影 + 负面词） |
| 5 | AI 生图进阶：改图与一致性 | 不只是抽卡，能精修 | 局部重绘 / 风格迁移 / 人像一致性 / 垫图；做一张公众号封面 |
| 6 | AI 生视频 | 做出第一条 AI 视频 | Sora / 可灵 / 即梦视频；图生视频 vs 文生视频；运镜词；做一条 5 秒短视频 |
| 7 | Boss：给 AI 配个"外挂大脑" | 综合实战 | 用 ChatGPT Projects 或 Claude Projects 建一个"专属助手"（喂 3 份资料 + 写 system prompt），完成一个真实任务 |

**待拍板**：
- Day 2「结构化输出」是否对小白偏技术，是否改名为"AI 整理信息神技"
- Day 4-5 生图工具：国内为主（即梦/可灵）还是国际为主（Midjourney/Sora）

## Week 4 — Agent 与 Harness：让 AI 自己干活

**目标**：从"AI 工具"升级到"AI 员工"。课程节奏 **概念:动手 ≈ 1:1**。叙事弧线：**先试 → 再用 → 再懂原理 → 再看天花板 → 毕业**。

**Harness 在本周的定义**：让 Agent 能"长时间自主干活"的工程骨架——管工具、管错误、管记忆、管停止。LLM 是发动机，Harness 是车身和方向盘。

| Day | 标题 | 概念/动手 | 核心收获 | 关键内容 / 用户怎么试 |
|---|---|---|---|---|
| 1 | **Agent vs Chatbot + 第一次试 Agent** | 半概念 / 半动手 | 一字之差天壤之别；知道有哪些 Agent 可用 | 概念：同一任务两种做法对比；常用 Agent 一览（秘塔 / Kimi 探索版 / 豆包 / Coze / Manus / ChatGPT Agent）。**亲手**：用秘塔 + Kimi 探索版各做一次"AI 替我跑腿"，对比普通聊天 |
| 2 | **用 Agent 干活（一）：信息类任务** | 动手为主 | 体感 Agent 解决"查 + 读 + 整理"的威力 | 4 个递进练习：① **陌生话题调研**（秘塔，示例：USDT 稳定币是什么） ② **长文档消化**（Kimi 文档对话 / 豆包，上传 30 页 PDF 让 AI 总结 + 抽关键条款） ③ **跨平台对比**（Kimi 探索版，示例：iPhone 17 / 华为 Mate 70 / 小米 16 拍照对比表） ④ **深度调研报告**（秘塔深度研究，示例：2026 年最值得关注的 5 家 AI 公司，1500 字）。配 quiz：Agent 背后到底做了什么 |
| 3 | **用 Agent 干活（二）：自动化日常** | 动手为主 | 从"用别人的 Agent"升级到"自己搭 Agent" | 上午看示范 + 下午动手：① **看示范**：录屏跟搭"每日新闻摘要 Bot" ② **动手 1**：跟着用 Coze 国内版搭"每日新闻摘要 Bot"（选 3 个新闻源 → LLM 摘要 → 推送到自己微信） ③ **动手 2**：搭"消息回复模板 Bot"（贴一段对方消息，生成正式/友好/委婉拒绝 3 种回复） ④ **选做**：搭"个人助理 Bot"（喂工作背景 + 写作风格，以后用你的口吻输出）。**关键设计**：故意让用户体验一次 Agent 跑偏/出错，为 Day 4 Harness 概念铺路——"被痛苦逼出来的概念"比干讲有效 |
| 4 | **Harness：让 Agent 长时间干活的骨架** | 概念为主 | 理解 Agent 为什么能跑半小时不崩 | 为什么 LLM 本身做不了 Agent？需要外面套 Harness（管工具/错误/记忆/停止）。比喻：发动机 vs 车身。**看录屏**：Claude Code 自主写完一个项目，标注每一步 Harness 在做什么 |
| 5 | **记忆：让 Agent 越用越懂你** | 半概念 / 半动手 | 理解长短期记忆为何是 Agent 持续工作的前提 | 短期记忆 = 上下文窗口；长期记忆 = 跨会话持久化（用户偏好 / 历史结论 / 文件库）。**亲手**：ChatGPT Memory + Claude Projects + 豆包记忆 三家对比，给自己的 AI 喂 5 条偏好，观察后续对话变化 |
| 6 | **业界优秀 Harness 巡礼 + 手机上的 Agent** | 看 + 选做 | 见识 Agent 时代的天花板 | 闭源 Harness：Claude Code / Codex / Manus；开源 Harness：**OpenHands**（原 OpenDevin）/ **OpenClaw 🦞** / **Hermes**；手机端 Agent：Manus 移动版 / 豆包 App / ChatGPT App 的 Agent 能力。**选做**：在手机上装一个试试 |
| 7 | **Boss：从 0 到 1 搭一个属于你的 AI 员工** | 纯动手 | 毕业作品 | 选一个真实痛点（写周报 / 整理资料 / 监控信息 / 自动回复），用 Coze 搭出来，跑通端到端，写一份"我的 AI 员工说明书" |

**节奏检查**：
- 概念占比：Day 4 + 半个 Day 1 + 半个 Day 5 ≈ 2 天
- 动手占比：Day 2 + Day 3 + Day 7 + 半个 Day 1 + 半个 Day 5 ≈ 3.5 天
- 看 + 选做：Day 6 ≈ 1 天
- 整体动手 > 概念，符合"小白要多动手"原则

**待拍板 / 备忘**：
- Day 3 / Day 7 都用 Coze，避免来回换工具增加学习负担
- 业界产品巡礼合并到 Day 6 一天讲完（不再像旧版拆成 Day 4 + Day 5），节奏更紧凑

## 外部依赖与"用户怎么试"分层策略

每个需要"体验"的环节，按三层供给降级：

| 层 | 形式 | 适用产品 |
|---|---|---|
| 第 1 层 | 亲手玩（practice step） | 国内免费四件套：**秘塔 / Kimi 探索版 / 豆包 / Coze** |
| 第 2 层 | 看演示（video step） | 闭源 / 付费 / 需梯子：**Claude Code / Codex / Manus / ChatGPT Agent** |
| 第 3 层 | 读案例（theory + quiz） | 实在用不了 / 偏开发者向：**OpenClaw / Hermes / Computer Use** |

设计原则：**主线体验锁定在第 1 层**（小白真能玩），**第 2、3 层用于科普业界天花板**（让小白知道世界长什么样）。
