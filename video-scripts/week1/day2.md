## 口播正文

你每天都在用 ChatGPT、豆包、Kimi。但你有没有认真想过——当你打下一句话、按下回车,它脑子里到底在干嘛?

很多人以为,它是先把整个答案在脑子里想清楚,再一口气写给你;还有人以为,它是偷偷上网搜了一下,把别人的答案抄过来给你。今天这条视频,我就想把这层窗户纸捅破。它真正做的事情,简单到你可能不敢相信——它只是在**猜下一个字**。仅此而已。

我们先把所有复杂的数学全部抛开。GPT 这类大模型,核心干的活只有一个,英文叫 Next Token Prediction,翻译过来就是**预测下一个词**。它不理解什么是真理,它只会算概率。

给你举个最直观的例子。你输入"白日依山尽",它会根据自己读过的海量文本算出来:后面接"黄河入海流"的概率高达百分之九十九点九。于是它就把这几个字吐出来了。注意,它根本不知道这是王之涣的诗,它只知道一件事——在"白日依山尽"后面,这几个字最该出现。

所以它最像什么?它最像你手机打字时的那个**自动补全、联想输入**。你打"今天天",它跳出"气";你打"我想吃",它跳出"饭"。大模型,本质上就是一个超级加强版的自动补全工具,只不过它补的不再是一个词,而是一整段话、一整篇文章、甚至一整段代码。

再看一个特别有意思的现象。如果你输入"番茄炒……",它很可能补"蛋",概率百分之九十;也可能补"西红柿",概率百分之五。但它几乎绝不会补"电脑"。为什么?不是因为它内部有个食物词典只准输出食物,也不是因为它"理解"了番茄是食材——而是因为:在人类写过的所有文字里,"番茄炒电脑"这个组合几乎从来没出现过,统计概率接近于零。**它靠的是统计,不是理解。** 这个直觉你一定要先建立起来,后面所有现象都从这儿长出来。

接下来是个关键细节。AI 并不是每次都死板地选那个概率最高的词。如果它永远只选最高的,说话会无聊得像复读机。所以它会在概率比较高的那几个候选词里,**随机挑一个**。这就解释了一个你肯定遇到过的现象:同一个问题,你问两遍,答案居然不一样。根本原因就在这——它在掷骰子。

也正是这个机制,带来了那个让无数人头疼的毛病:它会**一本正经地胡说八道**,我们叫它"幻觉"。为什么会这样?因为它的目标从来不是"说对",而是"说顺"。它是在生成一句看起来通顺的话,而不是去做事实核查。请你把这句话刻进脑子:**统计上通顺,不等于事实上正确。**

这里也能顺手分清一对最容易混的东西:搜索引擎和大语言模型,到底有什么不同?搜索引擎做的是"检索"——它去帮你找现成的网页链接;而大模型做的是"生成"——它逐词预测,现编一段新内容。所以它们本质完全不同,大模型并不是搜索引擎的升级版。你也可以这样记:计算器这种确定性的程序,一加一永远等于二;而大模型这种概率性的模型,同样的输入,输出可能每次都不一样。

那它到底是怎么把一段话写出来的?这里有个词叫**自回归**,英文 Autoregressive,听着吓人,其实特别好懂。它写文章不是一口气写完的,更像在玩**贪吃蛇**:先生成第一个字,把这个字加回到输入里;再生成第二个字,又把前两个字一起加回去;接着算第三个字……它就这么一节一节往前爬。换句话说,它生成第 N 个字时,必须先拿到前面已经生成的那些字,才能算出下一个字。

明白了这个,你就明白另一个现象了:为什么 AI 生成长文时,是一个字一个字往外蹦,而不是整段一下子显示出来?这不是服务器慢,也不是单纯的界面特效——而是因为自回归:它必须先把上一个字定下来、加进上下文,才能去算下一个字。**它是真的在边想边说。**

也正因为这样,它有个天生的软肋:**多步骤的数学推理**。因为它是顺着往下猜,一步算错,后面就步步错,而且普通模式下它没法回头修改。写诗、翻译它都不怵,唯独这种环环相扣、不能出半点错的长链条计算,最容易翻车。

那我们普通人,怎么才能让它更听话、更靠谱?答案藏在一个你天天在用的东西里——**Prompt,提示词。** Prompt 的本质,就是你喂给 AI 的"上文"。你给的上文越具体、限定得越死,它预测"下文"的概率空间就越窄,答案自然越准。你只说"写篇东西",它海阔天空;你说"用三百字、面向小学生、写一篇关于光合作用的科普",它的输出一下就被框住了。

这也解释了一个很有用的技巧:为什么你给它几个例子,也就是 Few-Shot,它就突然变聪明了?不是因为它把例子抄下来,而是因为这些例子作为上文,**调整了它预测后续内容的概率分布**,让它去模仿例子的模式。你给它看三个范例,它就顺着这个范例的调子往下接。

还有一招最实用:如果它老在瞎编事实,你该怎么办?反复喊"请不要编造"没用,把温度调到零也治不了乱编。真正有效的办法是——**把包含事实的参考资料直接喂给它**,让它基于你给的材料来回答。把它的概率空间死死压到正确答案附近,它就编不了了。这其实就是我们后面要学的 RAG 的思想种子。

最后,帮你把几个常听到的术语彻底分清。有人批评大模型只是"随机鹦鹉",意思是:它模仿人类语言模仿得特别像,但它并没有真正的理解和意识,本质上只是一台概率复读机。设置里那个**温度 Temperature** 参数,控制的是输出的随机程度:温度越低,每次越固定、越保守;温度越高,越发散、越有创意,但也越容易跑偏。还有几个词你会反复碰到:**训练**,是它吃海量数据、更新内部权重的过程,要烧大量显卡;**推理**,是它用训练好的权重来生成答案的过程,你调用 API 付的钱,扣的就是这一段算力;**上下文**,是它用来预测下一个词的依据,一旦超过上限,最早输入的内容就会被强制丢掉。

好,这条视频其实从头到尾只讲透了一件事:**AI 不是神,它是一个数学极好的接龙游戏玩家。** 它不停地在猜下一个字,猜得又快又像,以至于我们经常误以为它真的懂。把这个第一性原理记牢,你再回头看"它怎么又编了""它怎么每次答案都不一样""我怎么让它更听话"——全都是这一条原理的自然结果。
